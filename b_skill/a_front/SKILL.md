# Frontend

Antes de alterar a interface, identifique no código real a stack, o design system, os componentes compartilhados e os padrões de teste.

- Reutilize componentes e convenções existentes.
- Preserve responsividade, acessibilidade e consistência visual.
- Trate validação de formulários e estados de carregamento, erro e vazio.
- Confirme os contratos das APIs consumidas.
- Valide a alteração com as ferramentas de interface, lint, tipagem ou build já disponíveis.

Não introduza frameworks, bibliotecas ou padrões que não tenham sido confirmados no projeto.
